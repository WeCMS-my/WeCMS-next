# SqlSugar Native AOT Spike Spec

## Status

Archived historical research.

## Note

This spec is preserved only as historical AOT research.

WeCMS no longer treats Native AOT as the active runtime baseline. The active baseline is defined by `docs/specs/runtime-baseline-jit/` and `ADR-0009`.

## Current Relevance

- Keep as background material for past AOT investigation only.
- Do not use this spec as a merge gate, package admission rule, or release requirement.
- SqlSugar remains the ORM direction, but under the JIT runtime baseline rather than an AOT compatibility gate.
