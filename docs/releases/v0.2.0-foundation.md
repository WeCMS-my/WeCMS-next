# WeCMS Next v0.2.0-foundation Release Note

Date: 2026-06-23

## Summary

`v0.2.0-foundation` marks the foundation-stable baseline for WeCMS Next after Phase 1, Phase 1 hardening, production hardening, and the S1-S14 system-foundation upgrade.

This is a foundation freeze release note, not a production deployment record.

Local tag status at closeout:

```text
v0.2.0-foundation -> e19fcbea
```

This release-note file itself must be committed before it can be included in a pushed release tag.

## Highlights

- Accepted `.NET 10` + ASP.NET Core Minimal APIs + JIT publish/runtime as the active backend runtime baseline.
- Accepted SqlSugar ORM through `WeCms.Data.SqlSugar` and `WeCms.Modules.*.SqlSugar` boundaries.
- Accepted SoybeanAdmin / Vue 3 foundation admin frontend.
- Completed the responsibility-based module split for Identity, AccessControl, Organization, Configuration, Audit, Security, FileCenter, and Platform.
- Removed `WeCms.Modules.System` and `WeCms.Persistence` from active source.
- Froze backend, frontend, and production quality-gate entrypoints.
- Preserved OpenAPI as the backend/frontend contract delivery surface.

## Out Of Scope

This release note does not include:

- CMS content-management APIs or frontend pages.
- Legacy ThinkPHP runtime compatibility.
- Legacy data migration.
- Plugin runtime.
- AI runtime, AI providers, Prompt/RAG/vector store, or agent tooling.
- Real production deployment execution.

Before pushing the tag or deploying:

- Confirm the working tree is clean or intentionally staged.
